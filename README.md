 # My Learning Repository

This repository is my personal learning space. I use it to write down what I learn, practice new ideas, and keep small experiments and projects in one place.

## Topics

- Python programming
- Machine learning
- Deep learning and PyTorch
- Convolutional neural networks
- Data analysis with scikit-learn
- Experiment tracking with MLflow
- SQL
- CI/CD
- Mathematics for machine learning

## Repository Structure

- `Sourse/` - PyTorch, CNN, scikit-learn, and computer vision experiments
- `Deep Learning/` - Deep learning and mathematics notes
- `mlflow/` - MLflow experiments and artifacts
- `fast/` - Python practice projects
- `SQL/` - SQL exercises and assignments
- `CI/CD/` - Continuous integration and deployment practice

## Learning Notes

When I learn something new, I add code, notebooks, examples, or notes to the relevant folder. This repository is allowed to be experimental and unfinished.

- Understand machine learning concepts through practice
